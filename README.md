# Room Occupancy Classification

## a. Problem statement

Estimate the number of people in a room (0, 1, 2, or 3) from environmental sensor readings. Five classification algorithms are trained on the same dataset and compared on a held-out day. The Streamlit app loads saved estimators and evaluates labeled test CSV files without fitting or retraining.

## b. Dataset description

**Room Occupancy Estimation**, UCI Machine Learning Repository, dataset 864. The data contains 10,129 observations collected from non-intrusive temperature, light, sound, CO2, and PIR sensors. The original table has 18 predictors plus the target; this project excludes the `Date` and `Time` fields and uses the 16 numeric sensor readings as predictors. The target, `Room_Occupancy_Count`, has four classes: 0, 1, 2, and 3. The dataset has no reported missing values.

Source: [UCI Room Occupancy Estimation](https://archive.ics.uci.edu/dataset/864/room+occupancy+estimation) · DOI: [10.24432/C5P605](https://doi.org/10.24432/C5P605) · License: CC BY 4.0.

The training notebook downloads the original UCI ZIP archive. One complete date containing all four classes is held out for testing; all other dates are used for training. This keeps temporally adjacent samples from the same day out of both partitions. The selected test date, row counts, feature names, and scores are recorded in `model/metadata.json`.

## d. Models used

### Performance observations

Macro-averaged scores are included alongside accuracy to make performance on the less frequent occupied-room classes visible. The KNN model leads on accuracy, macro recall, macro F1, and MCC. The SVM achieves the highest macro AUC, while its thresholded class predictions score below KNN on accuracy and macro F1.

| ML Model Name | Observation about model performance |
| --- | --- |
| Logistic Regression | Strong and consistent scores across the four classes; second-highest macro F1 and a competitive MCC. |
| Decision Tree | Moderate results; lower macro F1 and AUC than the linear and distance/kernel-based alternatives on this held-out day. |
| KNN | Best overall by macro F1 (0.8922), accuracy (0.9083), macro recall (0.9007), and MCC (0.8751). |
| Gaussian Naive Bayes | Lowest scores overall, suggesting its conditional-independence and Gaussian assumptions fit these sensor readings less well. |
| Support Vector Machine | Highest macro AUC (0.9937), but lower accuracy and macro F1 than KNN at the default decision rule. |
| Overall winner for this dataset | KNN, selected by the highest macro F1; it also leads on accuracy, macro recall, and MCC. |

## Run locally

```bash
python -m pip install -r requirements.txt
```

Next, open `training.ipynb` in VS Code or Jupyter, select the project Python environment as the kernel, and run all cells. The notebook creates `model/` with all five fitted models and their evaluation metadata, and creates `test_data.csv` for the app. Then launch the app:

```bash
streamlit run app.py
```

In the app, upload any labeled CSV containing the 16 sensor columns and `Room_Occupancy_Count`. The app shows scores for all five saved models, plus the selected model's confusion matrix and classification report. Uploaded files must include all four target classes so multiclass AUC is defined.

## Files

- `app.py`: Streamlit evaluation interface.
- `training.ipynb`: reproducible dataset download, validation, split, training, scoring, and artifact creation.
- `requirements.txt`: runtime and training dependencies.
- `test_data.csv`: held-out labeled sensor readings generated by the trainer.
- `model/`: five serialized fitted estimators and metadata generated by the trainer.
